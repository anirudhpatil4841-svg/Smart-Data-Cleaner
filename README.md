# 🧹 Smart Data Cleaner

A Python-based web application built using **Streamlit, Pandas, and NumPy** to analyze, clean, and process CSV and Excel datasets.

## 🚀 Live Demo
[Click here to use Smart Data Cleaner](https://smart-data-cleaner-8hap7uo3bssjfae48crm9t.streamlit.app)

## 📌 GitHub Repository
[View Source Code](https://github.com/anirudhpatil4841-svg/Smart-Data-Cleaner)

## ✨ Features
- Upload CSV and Excel files.
- Preview uploaded datasets.
- Display total rows and columns.
- Detect missing values.
- Identify duplicate records.
- Automatically handle missing values using Median and Mode.
- Remove duplicate records.
- Display cleaned dataset preview.
- Generate cleaning summary.
- Download cleaned data in CSV and Excel formats.

## ⚙️ How to Run Locally

**1. Clone the repository**
```bash
git clone https://github.com/anirudhpatil4841-svg/Smart-Data-Cleaner.git
```

**2. Open the project folder**
```bash
cd Smart-Data-Cleaner
```

**3. Install dependencies**
```bash
pip install -r requirements.txt
```

**4. Run the application**
```bash
streamlit run app.py
```
